# Terra Character 界面风格

参考汇流的成就页、图鉴、扩展背包、秘密种子选择页及选择按钮。成就页的深灰面板、多重像素描边、金色分类高亮作为人物模块的主风格；取色板与 RGB 色条保留本身的颜色含义。

## 复用素材

- 原文件：`ConfluenceOtherworld/src/main/resources/assets/confluence/textures/gui/achievement.png`。
- 内置副本：`assets/terra_character/textures/gui/confluence_achievement.png`。
- 副本与原图像素相同，未裁切或重绘。SHA-256：`F71F08F0BF7791DBD3C1C2D950D35E399FFE9B878F3D031A4B817080AFEEE19C`。
- 素材来源、权利与许可沿用原项目；内置副本用于保持 Terra Character 独立安装，不需要加载汇流的类或资源命名空间。

`EditorUi` 通过九宫格取样保留边角与描边，对中间区域做伸缩，适配不同宽高：

| 用途 | 原图区域 `(u, v, w, h)` |
| --- | --- |
| 面板／人物卡片外框 | `(0, 20, 208, 184)` |
| 普通按钮／列表条目 | `(52, 208, 150, 13)` |
| 金色悬停／当前分类 | `(209, 31, 38, 38)` |
| 滑块手柄 | `(210, 10, 7, 15)`，高亮向右偏移 8 |

人物卡片使用金色选中描边；较大的去向选择框使用灰色面板与金色悬停边框，为后续插图留出空间。小按钮、下拉框、列表、标题、分档滑块与工具盒入口共用这些绘制方法。选择世界仍使用原版／汇流提供的界面。

风格改动不改变拖动方向、双击确认、绘制图层或人物存储逻辑。


## 像素布局约束

- 面板内边距至少 8 GUI 像素，列间距 8～10 像素；主操作按钮成对居中。
- 普通文字以原始字号在整数位置绘制，长文字截断并限制在内容矩形内；说明换行，长通知可滚动。省略的按钮和人物名称通过提示显示全文。
- 小屏取色器使用上下排列，RGB 标记与色条同排；选色标记裁剪在取色板内。
- 列表上下左右预留边框，滚动条有独立空间；弹出列表在调整窗口尺寸后重新限制宽度。
- 人物卡片与部件图库逐行居中，模型、信息栏和外框间保留固定留白。模型旋转时裁剪在所属展示框内。
- 金色高亮使用原图完整矩形框，避开顶部分类栏旁的装饰像素；九宫格保留边角及描边，材质本身没有重绘。

UI 专项客户端检查覆盖 640×400 和 320×240 GUI 尺寸：人物选择、回收站、创建人物、换装、部件图库、绘制皮肤、旅行工具、长通知和下拉菜单；检查控件越界、同层重叠并保存截图。未重复全量测试。

另外通过不加载汇流的独立客户端专项复查：下拉菜单在窗口缩小后跟随新按钮的位置与宽度，列表留白、高亮边框及控件边界正常。
