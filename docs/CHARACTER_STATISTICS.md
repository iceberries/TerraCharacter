# 人物统计

人物选择和回收站卡片显示最后保存的生命值／上限、魔力值／上限及累计游玩时长。魔力由可选汇流兼容提供，独立安装时隐藏魔力栏。卡片保留名称、难度和死亡状态；悬停可查看完整数值。统计从存档读取，不为了预览创建服务端人物或修改装备。

游玩时长按服务端实际人物 tick 累计，20 tick 为一秒，格式为总小时:分:秒。完成入场后才开始计时；选择界面、加载过程和单人暂停不计时。容器界面、死亡等待等仍属于游戏会话。计时器属于人物会话，重生或切换维度不会归零；跨世界、单人与多人切换时累计。同一个 tick 不因自动保存、退出保存等重复记账，计数溢出时饱和到 Long.MAX_VALUE。

新增可选 `Statistics` 存档段，保存 `Health`、`MaxHealth`、`HasMana`、`Mana`、`MaxMana` 和 `PlayTicks`。只保存摘要，不用于恢复人物属性；实际生命、魔力仍由原有适配器管理。自动保存、断开和服务器关闭会刷新摘要。异常退出只能保留最后成功保存／同步的统计，单人会话恢复与原有检查点一致。

旧存档无需转换：缺少统计段时显示已有生命与汇流魔力数据，未记录的上限需下次游戏保存后刷新；无法可靠还原的历史游玩时长从零开始。人物外观编辑、归档、恢复、备份保留统计。

统计随人物的可携带数据同步，继续采用客户端为准的冲突规则；服务端世界数据、原版世界内统计和成就仍维持原归属。旧三段可携带数据可读取并补齐默认统计，新传输增加 `Statistics`，网络协议从 7 更新为 8，联机双方需要更新到同一版本。存档格式版本仍为 1。

`CharacterStatisticsEvent` 供可选集成补充魔力。服务端保存时提供玩家；读取没有摘要的旧离线存档时不提供玩家，只提供适配器数据副本。核心不直接引用汇流类。
