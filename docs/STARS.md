# 人物与世界星标

人物卡片右上角和世界列表行右侧提供同款星标按钮。点击只切换星标，不选择或进入人物／世界，也不会触发双击进入。

人物、世界分别使用 `ArrayDeque` 队列保存打星顺序。星标项置顶，最近打星的在前；队列仍按打星时间保存，显示时从队尾向前读取，兼容已有星标文件。取消星标后回到未星标项原来的排序，再打星会显示在最前面。未星标项保留原排序。翻页、搜索和重新启动不会改变队列顺序。人物回收站不提供星标操作，恢复人物后沿用原星标位置。

偏好文件位于当前游戏目录：

- `terra_character/stars/characters.json`，以人物 UUID 标识。
- `terra_character/stars/worlds.json`，以世界存档文件夹标识，世界改显示名称不会丢失星标。

星标属于本机界面偏好，不修改人物／世界存档，不参与联机同步。世界选择沿用原版界面及汇流的图标等扩展，只增加行内按钮和排序；世界数据工具列表共用世界星标队列。

保存先写临时文件，成功后替换偏好文件并更新内存队列。写入失败时保留原状态；损坏或未知版本的偏好不会被覆盖，也不会阻止正常选择人物／世界。可修复对应 JSON 后重启游戏重新加载。
