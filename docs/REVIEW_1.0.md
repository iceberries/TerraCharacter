# TerraCharacter 1.0 审查

范围为 TerraCharacter 核心、内置汇流兼容代码及其测试。汇流等其他子项目不在本次修改范围内。

## 修复记录

| 风险 | 改动 |
| --- | --- |
| 账号皮肤请求超时后，后台工作仍可能更新全局皮肤；切换账号后旧请求仍可能写回 | 后台只返回请求自己的结果；经过超时处理后统一发布，发布时检查账号请求代次。缓存回退也属于本次请求。 |
| 适配器在模组加载期间注册，运行期校验直接读取可变 HashMap | 注册使用同一监视器；校验取得不可变快照，在锁外调用扩展代码，避免扩展回调与注册锁互相等待。 |
| 世界启动后台任务读取可变的客户端选择 | 在客户端线程捕获人物 ID、存储对象及存档目录，后台仅使用捕获值。缺失选择返回明确错误。 |
| 配置阶段断线清理与远程会话创建、令牌绑定交错 | 远程创建、清理和绑定使用同一监视器；绑定检查会话是否还存在，已加入标记保证跨线程可见性。 |
| 退出和断线可能重复关闭同一人物锁 | 锁对象改为私有字段，实现同步、幂等关闭，仅公开有效性查询和关闭接口。 |
| 保存退出确认可重复携带刚刚保存的版本 | 同版本内容一致时不重复落盘，但仍执行退出确认；同版本内容冲突时拒绝保存。 |
| 启动下一台服务器时残留握手状态 | 停服时清理挑战与传输记录。 |
| 入站状态包在玩家已经离开后才执行 | 执行时重新检查玩家和连接。 |
| 存储问题列表边写边复制 | 问题快照与扫描使用一致的同步机制。 |
| 异常消息为空时，错误列表与界面继续触发空指针 | 世界条目与人物损坏报告提供非空错误文本，保留无法加载的条目供用户处理。 |
| 可变公开字段绕过更新约束 | 人物选择、联机选择、世界选项及可选界面工厂改为私有字段和访问方法；世界选项返回不可变快照，工厂拒绝重复注册。 |
| 预览事件直接暴露可变 NBT | 字段私有化，读取 NBT 返回副本。 |
| 同一部位的大小写别名覆盖彼此 | 预设部件和范围按枚举键检测重复，拒绝冲突资源。 |
| 相对文件名没有父目录导致原子写入空指针 | 写入前规范化为绝对路径。 |

## 边界与风格

- 继续以 `api` 中的仓储、数据适配器、模型及事件作为公共契约；客户端界面工厂先定义接口，兼容模块实现并注册。内部工具保持包级或私有，不为实现细节增加公共接口。
- 未安装汇流时不解析兼容实现；兼容客户端入口仅在物理客户端加载。Mixin 插件使用加载器的已发现模组列表，而非尚未初始化的运行期 ModList。汇流世界初始化使用 LOWEST 优先级，在核心会话初始化后读取配置。
- 客户端预览、调色缓存及界面状态由客户端线程使用；网络处理先 enqueueWork，世界保存由服务器线程执行。线程安全容器不能替代 Minecraft 对象的线程约束。
- 唯一身份、资源与部位使用 Map；排序、像素序列、绘制顺序及分页列表保留 List，避免失去顺序语义。
- Java 源码使用 TAB 缩进、4 列显示宽度、驼峰方法与变量名，类型通过 import 引入。保存格式中的历史资源 ID 与键名不改动。
- 公共静态常量、记录类型访问器、框架要求的事件处理器、Mixin 的 @Shadow 字段及覆写方法保留必要可见性；不通过对象访问静态方法或字段。
- 编译器持续启用 static、rawtypes、unchecked、fallthrough 检查。未引入额外运行时依赖；格式化工具仅位于忽略的 build 目录。

## 验证

本次增加并发注册与校验、锁重复关闭、无效注册、冲突预设、空传输分片及相对路径写入的回归检查。账号皮肤隔离客户端还检查旧账号请求与超时后迟到结果不会替换当前皮肤。具体执行结果以本轮构建日志和隔离客户端报告为准。

- 模块单元测试：81 项通过，0 失败；随后补充世界错误文本防护，对涉及的仓储与安全检查专项复验 17 项，全部通过。日志：`build/review-check.log`、`build/review-final-check.log`。
- 独立客户端：通过，涵盖账号皮肤旧请求、超时回退、染色与双层皮肤。日志：`build/review-account-client.log`。
- 汇流兼容客户端：通过，八个适配器、客户端工厂和条件 Mixin 均正常加载。日志：`build/review-confluence-client.log`。
- 双客户端 TCP 联机：通过，包含 A/B/A 人物切换、资产与统计隔离、软核／中核／硬核、最终保存确认、大分片传输以及联机 → 单人 → 联机往返。两端报告：`build/multiplayer-smoke-host/mp-result.txt`、`build/multiplayer-smoke-guest/mp-result.txt`；日志：`build/review-multiplayer-client.log`。测试选择逻辑已适配新版人物卡片及分页。
- 编译未出现本轮 static、rawtypes、unchecked、fallthrough 检查的警告；现有 NeoForge API 过时提示保留。
- 未发现 Gradle 子项目循环依赖。客户端两个加载组合和联机内置服务器已验证，本轮没有单独运行专用服务器进程，也不据此保证任意第三方模组组合都没有加载问题。

发行 JAR 已确认版本元数据为 `1.0+1.21.1`，且不包含冒烟测试类；对应源码包一并生成。

版本配置为 `mod_version=1.0`，发行文件名继续包含 Minecraft 版本后缀。存档格式和网络协议未因接口整理而变更。
